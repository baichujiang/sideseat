# 公共计划中的游客身份与恢复

2026-10-21。用户批准无需注册登录、同名独立、个人恢复链接，并保留旧填写。

每次首次参与创建独立 guest ID 与 256-bit 随机凭证。名字仅为显示内容，新名字或同名都不能认领其他记录。服务器仅保存凭证 SHA-256；浏览器使用当前计划路径下的 HttpOnly、生产 Secure、SameSite=Lax Cookie 记住身份。所有游客写入继续核对页面的 participant ID 与已验证凭证，阻止另一身份或旧标签页串写。

网页提供个人恢复链接，使用独立 /time-poll-recovery/ 网页入口，避开已缓存的 iPhone 通用链接规则；安装了 App 也不要求游客登录。私密凭证放在 URL fragment，页面立即清除地址中的 fragment，再通过 POST 校验并恢复 Cookie；凭证不进入服务器访问日志或普通请求 URL。已提交时间和邀请回复保存在服务器，恢复不另建游客、重复计票或重置回复。未提交草稿仅保留在原浏览器。个人恢复链接是修改钥匙，只应本人私密保存；凭证与链接都遗失时不能凭姓名自动找回。

## 旧记录

- 原浏览器持有可验证的旧随机凭证：首次访问自动换成独立的计划凭证，保留 guest、response、invitation ID 及原数据。
- 只有原参与人 ID Cookie 或名字：不授予修改权，原填写仍保留。网页提示联系发起人；发起人在 App 参与名单中确认记录归属，再生成并私下分享恢复链接。
- 发起人只可为尚未领取私密身份的旧记录生成链接。重新生成会替换尚未领取的旧链接；游客领取后，服务器拒绝发起人重置。这一迁移不会修改时间、回复或自动写入日历。
- 新的游客记录从创建时即受保护，发起人不能借旧记录迁移入口取得其修改权。原生账号与个人日历权限保持原有登录规则。

复用已有 credentialHash 字段区分旧记录、待领取恢复和已保护记录，无 Schema 或批量数据迁移。
