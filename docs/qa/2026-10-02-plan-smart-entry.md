# 计划编辑页顶部的智能约时间（2026-10-02）

按用户指定的「添加日程 → 智能添加」布局，把推荐入口放在 PlanCreateSheet 顶部，采用星光图标、标题、右箭头的紧凑白色行。原来的日期、开始／结束时间、活动、地点和备注保留直接编辑。聊天上方的独立智能按钮已移除，聊天左侧原计划入口打开同一编辑页。

点击顶部按钮打开现有原生推荐弹层。选择后只更新当前草稿的起止时间并返回；取消不会修改草稿。已有活动来源和标准计划提议／接受流程保留。无需先选择手动／智能模式。

## 验证

Development 与 Preview 构建成功。5 项当前入口 UI 场景最终通过：

- 一次显示三个时段、换组、选择回填、发送返回聊天。
- 填写标题和地点后打开推荐；取消保留文字及原时间，再进入选择则仅更新时间。
- 不打开推荐，直接通过手动表单发送；时间控件无折叠并可点击。
- 无空闲时段状态。
- 日程读取失败与重试状态。

r2 中后四项通过；草稿保留检查因两层导航栏同名「取消」按钮定位歧义失败，限定推荐弹层导航栏后 r3 单独复测通过。早期 r1 的全屏滑动落在键盘／底部操作区，改为在可见表单内滑动后验证通过。这些修正均为测试定位，未改变产品交互。

额外尝试的旧 Discover `testActionInterestOpensContextAndPrefillsPlan` 在到达表单之前找不到已退役入口，其 fixture 实际启动到 Together；本轮未修复旧入口或把它计作通过。当前来源传递代码未改，草稿保留由新入口测试覆盖。

已检查 iPhone 13 mini 截图与 `git diff --check`。UI 使用认证 fixture，未向真实联系人发送计划。本轮无后端或数据库变更。
