# Plus 身份标识

日期：2026-09-26。状态：开发版完成，本轮未部署服务端或上传 TestFlight。

统一使用金色星形 `PLUS` 胶囊，浅色模式深金文字、淡金底；深色模式亮金文字、深金底。覆盖“我”顶部、公开资料、推荐/收藏、更多推荐、消息请求、聊天列表、私聊标题和聊天信息页。标识与蓝色学生认证分开；大字体推荐卡将名字和徽标分行，避免名字被挤成省略号。VoiceOver 标签支持中英德。

本人使用现有会员接口及兑换后的同一 MembershipStore；公开数据增加可选 `isPlus` 布尔字段，旧接口和旧缓存缺字段时不显示。服务端按当前有效期判断；再次加载后，过期会员恢复普通展示。公开响应不带会员到期时间、付款信息或邀请码。资料、推荐和聊天通过现有查询加载关系；聊天列表只做一次批量会员查询。无需数据库迁移。

OpenAPI 已同步并通过脚本重新生成 Swift 客户端；保留当前工作区已有未发布的接口变更。

## 验证

- 7 项本地真实数据库/HTTP 测试通过、0 跳过：公开资料、聊天列表、聊天页 Free/Plus/过期状态；推荐、收藏的有效/失效状态；不泄露会员详情；原有推荐收藏闭环。
- TypeScript、修改文件 ESLint、OpenAPI 177 个操作契约验证通过。
- iOS 构建及 2 项 UI 测试通过，结果 `/tmp/sideseat-plus-badges-fixed.xcresult`：本人 Free/Plus/已过期三种情况；德语深色最大辅助字体的推荐卡。
- 已人工式查看截图，确认个人页正常字号清楚、深色最大字体下名字完整可见。初版发现名字被徽标挤占，已通过分行布局修复后重测。
- UI 使用仅 DEBUG 的 `--ui-testing-plus-member` 和 `--ui-testing-plus-expired` 测试状态。未改动正式账号会员记录。
