# Preview 133 活动与时间融合验收

2026-10-19，Europe/Berlin。本轮核心融合已交付；初始失败和最终通过分开记录。

## 本次范围

以 Howbout 的计划组织方式为参考，结合 Timeful 的直接选时、Tricider/PollUnit 的活动提议与兴趣、Rallly 的复核发送，使用 SideSeat 现有实现融合在同一计划中。没有引入第三方产品代码、SDK、数据库迁移或新权限。

App 与网页取消活动提议/时间表视图切换；活动建议原位展开，App 添加提议也在原页输入。时间表始终可用。原生所有字号采用同一整页纵向滚动，日期继续横向滚动。仅表达兴趣的参与者仍需填写空闲，不会被提前移到等待。发起人可先选时，再在同一复核页选择活动和名单；返回改时间保留草稿，发送之前不写活动选择。发送依次调用已有选活动及邀请接口；如邀请发送失败，已保存的活动仍保留供重试。

保留 Preview 132 默认单表单、待处理纵向/等待横向、自动保存与撤销、逐人确认、同版全员确认后唯一日历、取消及过期规则。个人日历叠加、成员筛选和复制计划属于后续增强，本轮不宣称实现。

## 初始失败与修正

初次默认真机流程在普通滑动检查处失败：脚本沿用独立网格滚动的一次离屏要求。本轮已改为整页滚动，脚本改为核验首格实际向上位移及选中状态不变，再验证重开与服务端数据。初始部分 API 阶段及失败摘要保留，不能算完整流程通过。另一次命令使用不存在的测试选择器，执行了零用例，未计入通过数。活动混合运行在大字号阶段仍要求底栏存在复制按钮而失败；统一页面后参与者的复制入口位于既有更多菜单，脚本改为实际打开菜单并复制，单独重跑。第二次活动运行在草稿保留处误将中文无障碍值「已选择」与英文 Selected 比较而中止；实际草稿已保留且未提交，8 个 API 阶段通过。修正中文断言后，以新账号重新完整运行，最终 344.053 秒通过；产品代码未因这些脚本失败而改变。

候选首次自动化请求遇到部署保护（401），开发 OIDC 对 Production 目标未获准（403）。使用现有 Vercel CLI 认证及私密授权 cookie 后完成测试，没有关闭或扩大部署保护；失败尝试未创建账号。
