# 日历“今天”和添加入口调整（2026-09-27）

- “今天”从视图切换栏移至底部右侧，周视图与 3/5/7 天宽度选择同排；日/月视图也保持底部右侧位置。
- 添加日程移到顶部导航栏右侧，仅显示“＋”，48×48pt，略大于原有三个 44pt 工具按钮。
- 添加入口改为浅蓝底与深蓝图标，深色模式使用深蓝底与浅蓝图标；保留“添加日程”的辅助功能名称。
