# Preview 154：共同计划编辑页紧凑排版

将能在同一行看懂的信息放在同一行，保留长内容和辅助功能字号的完整阅读空间。

| 位置 | 调整 |
| --- | --- |
| 编辑计划信息 | 活动名称/地点采用左标签、右输入，与日期/时区共用一个表单组 |
| 候选日期与时区 | 左标签、右值；日期省去重复星期，说明放在组下方，减少独立标题与空行 |
| 编辑昵称 | 昵称标签与输入同排，解释保留在下方 |
| 我的参与信息 | 标签、昵称、编辑入口同排 |
| 核对邀请 | 活动与地点能放下时同排；日期用本地化时间区间，时区紧随其下，调整按钮在右侧 |
| 邀请名单与参与进度 | 姓名/身份与状态同排，放不下时恢复纵排 |

`PlanAdaptiveRow` 用实际内容宽度决定横排或纵排，辅助功能字号直接纵排；
输入字段保留原辅助功能标识与提交方式。没有改变计划数据、API、草稿或邀请合同。
