# 分享网页：在时间表中直接填写空闲

2026-10-18，Europe/Berlin。用户要求朋友网页与原生发起人时间表一致，取消填写/结果切换，改完重跑完整流程。
网页产品来源 `9f3d9f1d`，已提交推送；原生仍为 Preview **119**。

## 行为与数据边界

填写或继续原来的名字后，网页显示一张可编辑的「大家的时间表」。
点选/取消、长按拖选、当天选择、撤销继续修改自己的空闲；勾选和边框标记自己的选择，数字表示完整覆盖半小时的总人数。
人数计算用当前草稿替换自己已保存的一份答复，朋友的答复保持原样。
自动保存后和刷新重开时表格都保留，不再出现「保存并继续」「改我的空闲」「看大家填写」视图切换。
保存反馈和下一步说明常驻底部：填写空闲不等于参加，发起人定最终时间后，回到本页明确确认。

固定时间邀请仍跳过空闲，名字不自动接受邀请。游客同名继续、改名/切换填写人、邀请版本、人数和 Calendar 规则保持。
本轮只更新三个网页 UI 文件；API、数据表和原生产品代码没有更改。
