# 分享页与 App 视觉统一

2026-10-04。

分享页应延续 App 的视觉语言，让用户打开 App 后能认出相同的卡片、消息和操作。公开页仍围绕“意愿 → 联系 → 注册 → 打开 App”展开，保持首次访客所需的简短路径。

| 项目 | 原有差异 | 本次调整 |
| --- | --- | --- |
| 阅读层级 | 标题偏大，正文与辅助信息偏小，暖灰色过多 | 系统字体优先；标题 26px、正文 16px、辅助信息 12–14px，主次对比更清晰 |
| 页面与卡片 | 固定暖白背景，手机尺寸间距不一致 | 对齐系统分组背景、Together 24px 圆角 / 20px 内边距；窄屏适度收紧 |
| 按钮和表单 | 13px 圆角、不同中性色、若干小触区 | 14px 控件圆角，主按钮至少 50px，工具与次级动作至少 44px，输入字号 16px |
| 操作颜色 | 普通操作深酒红，App 入口玫红 | 普通操作沿用 ProductAction 墨色/浅色，打开 App 使用 accent 玫红/黑字 |
| 消息 | 两种暖灰气泡 | 复用 Chat 的灰色对方气泡、灰玫红己方气泡及各自文字色，计划卡片单独分层 |
| 系统外观 | 固定浅色 | 跟随 prefers-color-scheme；深色沿用原生对应配色 |

依据：`SideSeatTheme.swift`、`SSPrimaryButton.swift`、`SSTextField.swift` 和 `docs/DESIGN_SYSTEM.md`。Web 使用对应语义的局部 CSS 变量；没有改动原生主题或增加新的流程说明。

验证：开发服务浏览器检查通过，无错误覆盖层；已有 App 衔接用例 5/5，24.1 秒，覆盖游客注册、日程保存/取消、计划接受及注册后刷新失败恢复。320px 深色窄屏复跑注册衔接 1/1，5.5 秒；包含中英德语言切换。已检查浅深色首屏、注册成功和聊天截图。未新增重复样式断言。正式部署及实际设备边界见 release 记录。
