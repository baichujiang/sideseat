# 今天日期高对比度高亮

日期：2026-10-02。按用户要求，提高日历中今天日期的辨识度。

- 月、周、日共用实心蓝色日期标记，替代浅红底；今天不再被普通日期的选中色覆盖。
- 浅色模式深蓝底配白字，文字对比度约 7.59:1；深色模式亮蓝底配深色字，约 8.68:1。数值按实际 token 的 sRGB 相对亮度计算。
- 根据后续反馈移除最外侧轮廓，仅保留实心蓝色圆标；选择其他日期后，今天仍保留蓝色圆标。月视图相邻月份中的今天也保持完整对比度。
- 当天的星期和日程分组标题使用相同蓝色。当前时间线继续使用原有时间标记色。

iPhone 13 mini / iOS 26.5 模拟器验证通过：30 项现有主题对比度测试；浅、深色模式分别运行月／日切换与周视图回到今天两项 UI 测试，共 4 次通过。已人工检查月、日视图的浅深色截图；模拟器外观已恢复为原来的浅色。
