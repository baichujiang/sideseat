## 实际行为

发起人的征集详情直接使用可编辑的人数时间表：点按切换自己的空闲，长按拖选、点日期选择当天和撤销继续可用。
勾选与边框表示自己的选择，数字表示完整覆盖该半小时的总人数；旧半格仍显示部分选择。
本地草稿只替换自己的一份答复，人数不会重复计算自己，也不会修改朋友的空闲。
底部持续显示保存中、已自动保存或失败反馈；保存和重开都保留同一张可编辑时间表，无需完成或切换模式。
名字预填并可修改，分享随时可用；朋友填写后继续可选最终时间和名单、邀请确认。

本轮仅原生更新。参加者保存后的等待流程、网页、邀请/改期规则、API、数据库和日历确认规则保留。
另选邀请时间时仍是只读查表，不在邀请确认阶段改写已征集答复。

  直接拖选自己的空闲 → 取消/撤销 → 当天选择/撤销 → 自动保存 → 重开保留选择 →
  系统分享/复制 → Safari 游客填名选时 → 原生表中取消自己的时段，仍显示朋友的 1 人空闲 →
  保存重开仍保留 → 恢复为 2 人空闲 → 定时间/名单并邀请 → 游客明确确认 → 日历搜索/详情 → 返回同一计划。

  取消自己的首格后本人仅保留后两个 quarter-hour ID，朋友四个原 ID 完整保留；恢复后两人数据正确。
