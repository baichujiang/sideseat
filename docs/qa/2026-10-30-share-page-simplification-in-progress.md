# Shared-plan page simplification — in progress, not deployed

The public shared-plan page was simplified for desktop and mobile browsers. The initial name-entry view is narrower on desktop, the event details and navigation are more compact, repeated prompts were removed, and recovery guidance is available on demand. The timetable and invitation retain their existing interactions, date boundaries, private recovery mechanism, time zone, and the distinction between availability and confirmed attendance. This is responsive web work; no native App build was changed or installed.

Local in-app-browser checks covered a 1440×900 desktop view, 390×844 mobile view, and 320×720 English view without document horizontal overflow; the actual visual captures used the current dark appearance.
