# 智能约时间 UI（2026-10-02）

推荐弹层改为紧凑分组列表：左侧日期，右侧时间范围及空闲时长；「换一组」放在列表标题旁。顶部显示当前活动及简短操作提示，右上角关闭。无空闲或加载失败可返回手动填写。默认使用 72% 高度弹层，较大字体使用全高；辅助功能字号下采用上下排版。

本轮仅调整呈现和导航提示。活动名称用于上下文，未参与排序；现有空闲筛选及一次发送一个计划时间的机制不变。

## 验证

在 iPhone 13 mini / iOS 26.5 模拟器认证 fixture 中，6 项相关 UI 场景完成验证：

- 三条时段、换组、选择回填、发送后返回聊天。
- 填写活动及地点后关闭推荐保留草稿，选择仅更新时间。
- 直接手动填写和发送。
- 无空闲时段及返回手动填写。
- 日程读取失败及重试。
- 德语深色模式、中文最大辅助功能字号下关闭与点选回填。

r1 中手动、无空闲和错误场景通过；其余检查暴露了时间行缺失按钮辅助功能特征。补回 `.isButton` 后 r2 三项复测通过。r2 截图显示测试注入的大字体未实际进入弹层，因此未将该截图视为大字体证据。r3 改用系统字号启动参数并断言行高，发现大字号标题与图标拥挤；调整为上下布局及独立关闭图标尺寸后，r4 深色／大字体复测通过并检查截图。

三种语言资源通过 `plutil -lint`；`git diff --check` 通过。Development 测试构建及 Preview 69 构建通过。测试未向真实联系人发送计划；真机交互未纳入本轮自动化范围。
