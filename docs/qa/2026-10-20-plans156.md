# Preview 156：活动待定与时间已定可组合

## 完整流程

同一创建表单勾选「让朋友提议活动」并设置确定时间，保留活动、地点、候选日期、确定时间、时长和人数。创建后仍在筹划阶段，显示只读的已定时段和活动建议。App 联系人及网页朋友可提议或表达兴趣，无需填写空闲，也不默认参加。发起人核对活动和名单后明确发正式邀请；参与者明确接受；发起人正式发出后才写入接受者日历。

实现继续使用原计划、时间字段、活动提议、邀请和发布接口，没有新数据库字段、迁移或独立模式引擎。固定时间且活动待定时为 FIXED/COLLECTING/version 0，邀请/答复为空；选择活动不会改变已定时间，没有新地点的建议保留共同地点。明确发送后才进入 INVITING/version 1。未确认的筹划在确定开始时间到期。
