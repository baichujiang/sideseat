# 以活动与时间为中心的计划卡片

日期：2026-09-26。范围：原生计划列表；本地开发版本，未发布线上或 TestFlight。

## 设计落实

- 活动标题位于左上，状态位于右上；辅助大字号时上下排列，允许完整换行。
- 时间作为第二层重点，随后是地点、小头像和同行者名字。
- 移除大面积分类色块，以中性卡片和小分类色点展示；自定义计划不猜测活动类别。
- 待本人确认显示「查看并回应」，其他普通卡片显示「查看聊天」。整张内容区仍进入原会话中的计划位置。
- 改期的长解释移出列表；状态仍提示改期，原会话内保留改期说明和确认行为。
- 已结束且可反馈的卡片底部只显示发生情况反馈，不同时占用一行聊天操作。填写后显示结果与修改入口；卡片主体仍可进入会话。
- 「已结束」只表示时间已过，不自动将计划标记为已完成。反馈、聊天、日历的数据规则不变。
