# 邀请码管理后台交付与验证

日期：2026-09-26。本文记录发布前的本地验证。

后续状态：用户确认后已于当日上线，Pipi 正式管理员权限生效；详见 [上线记录](../releases/2026-09-26-membership-admin-production.md)。下文的「尚未上线」为本轮本地验证完成时的历史状态。

## 功能

- 独立网页 `/admin/invitations`，复用已有账号登录；未登录跳转登录页并保留目标地址。
- 批次创建：名称、共享/独立模式、1–500 个名额、1–3650 天 Plus、兑换截止时间。
- 原始邀请码一次性展示，支持复制和 CSV 下载；数据库与查询接口不返回原码或摘要。
- 分页查看批次、每码使用情况、兑换记录和操作记录；单码/整批停用。
- 创建请求使用唯一请求键：重复或并发请求只创建一批。原文丢失时不伪造恢复，可查看已创建批次并停用。
- 共享名额继续复用已通过验证的事务计数；停用不撤销已有会员。

## Pipi 授权状态

已通过原项目配置对远程库执行定向只读查询，找到唯一的 `pipi` 正式账号，非游客且已完成账号设置。没有创建同名账号，也没有更改密码。

该账号的固定 ID 已加入**当前活动开发目录**的 `.env.local` → `ADMIN_USER_IDS`；服务端按 ID 校验，因此改用户名不会丢失授权，其他人注册同名账号也不会继承权限。测试服务器另外临时允许一个隔离测试账号；此测试授权不写入项目持久配置。

**线上配置和运行版本尚未更新，所以不能声称 Pipi 已可登录线上后台。** 本轮没有生产写入、生产迁移或部署。发布时需把核验过的账号 ID 配置到目标运行环境，应用会员基础/后台迁移并发布相应后端。当前工作区还包含此前未发布的交互修改，发布范围需单独确认。

## 当前限制

- 不提供关闭页面后找回原码；请及时保存下载文件。
- 原命令行生成的无批次邀请码暂不纳入网页列表，仍由脚本管理。
- 不提供网页授予管理员的入口，管理员名单只能通过可信运行环境配置。
- 账号删除后旧兑换明细随账号删除，但邀请码已用次数不返还；操作者审计身份保留。
