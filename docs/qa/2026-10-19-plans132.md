# Preview 132 默认主流程与单表单创建

2026-10-19，Europe/Berlin。按用户要求，用一个默认主流程替代入口模式二选一和强制下一步。

## 行为

计划 → 发起计划 → 输入活动名、可选地点及时间 → 创建时间表 → 直接填写/分享。候选日期默认未来七天，时间摘要常驻；修改时在原页展开日期和时段。没有「已想好活动 / 一起选活动」顶部分流，也没有「时间未定 / 已定」成对卡片或强制 Next 页。

「还没想好做什么？让朋友提议」是活动字段下的次要文字入口；「时间已定？直接发邀请」是时间字段下的次要入口，点击后原位显示明确时间、时长和人数。返回默认状态保留活动、地点及候选日期。已存在的计划、提议/兴趣、直接选空闲、同表选最终时间、邀请名单与明确参加规则不变。
