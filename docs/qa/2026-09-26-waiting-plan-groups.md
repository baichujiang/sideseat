# 等待回应的计划分组

日期：2026-09-26。原生开发版本，尚未发布线上或 TestFlight。

「等待回应」页分为上方的「待我回应」与下方的「等待对方」，标题旁显示各组数量。每组沿用原来的时间排序；没有内容的组不显示。待处理的计划按当前提议的接收人／发起人分组，改期提议同样适用。

卡片继续使用活动、时间、地点、同行者的排列。待我回应的卡片显示「查看并回应」，发出的卡片显示「查看聊天」；计划处理仍在原会话内完成。「即将开始」和「已结束」维持原来的分类方式。

仅修改原生列表呈现与本地 UI 验证场景，不修改服务端数据或接口。
