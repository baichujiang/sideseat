# Preview 131 一起选活动起点

2026-10-19，Europe/Berlin。新增可选主题起点，保留已想好活动、横向等待区及既有确认规则。

## 最终行为

「计划 → 发起计划 → 一起选活动」输入主题即可创建，默认未来七天，日期和时段按需调整。App 参与者和分享网页游客都可以提议活动、同时标记多个兴趣。发起人先选择候选，再明确「确定活动，继续约时间」。原链接、昵称、参与者和已填空闲保留；未选活动时也能先填空闲。之后沿用同表选时 → 核对名单 → 发送邀请 → 每人明确确认 → 日历。

感兴趣、填写空闲和确认参加是三个独立动作。票数不自动决定活动，不强制等所有人投票，也不提前写日历。聊天原有双人计划保持原规则；在聊天中打开这个分享链接，进入同一个手动计划。
