# 分享页跟随访客语言

2026-10-04，Europe/Berlin。

意愿分享页从访客请求的 `Accept-Language` 选择中文、德文或英文，支持地区变体及偏好权重；未支持语言回退英文。首次服务端渲染就采用该语言，正常页及失效提示均有对应 `lang` 标记，不读取旧网页的 `NEXT_LOCALE`。

手动切换保存仅用于分享页的语言 Cookie，刷新后继续使用。明确的旧 `?lang=` 链接仍可指定语言；手动切换会移除参数，复制分享链接也会移除参数，避免把自己的语言强加给下一位访客。优先级为明确链接语言 → 本浏览器手动选择 → 浏览器语言 → 英文。

验证：

- 新访客中文、德文地区变体、英文显示正确；法语回退英文。
- 原始服务端 HTML 与加载完成后的语言一致，旧网页语言 Cookie 不干扰。
- 手动切换、刷新保持、转发给另一位中文地区访客、失效页面语言通过。
- 分享时间过期恢复与正文保留的现有浏览器回归通过。
- 定向 ESLint、源码 TypeScript 检查及 diff 检查通过；React 最佳实践复查未发现新增的客户端判断闪烁或重复状态问题。

首次语言测试的 fixture token 少了八位，导致显示失效页，修正 fixture 为规定的 48 位后通过。默认 TypeScript 检查混入旧 `.next` 的生成路由类型，隔离该生成目录后源码检查通过；正式云构建的 lint 与类型检查随后通过。发布验收脚本首次漏带 API 所需的幂等键及删除账号确认字段，补齐后八项语言检查和清理全部通过；前两轮残留的两个隔离数据库 QA 账号已删除。没有为这些测试环境问题改动产品逻辑。

候选及正式站点分别八项语言验收通过，QA 账号均已清理；正式部署健康检查通过。
