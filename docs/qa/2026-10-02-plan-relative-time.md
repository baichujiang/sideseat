# 计划的相对时间提示（2026-10-02）

计划列表和聊天计划卡片在原日期／时段行加入辅助提示，不新增卡片模块。即将开始列表的分组标题保留完整日期；卡片展示「明天」「N 天后」，当天则依距离显示「今天」「约 N 小时后」「1 小时内」。已确认且 30 分钟内开始的计划显示「即将开始」，到开始时间显示「进行中」，到结束时间显示「已结束」。结束不自动记录已完成反馈。

待回应提议不会显示「进行中」；取消、拒绝、过期或被替代的计划不显示倒计时。按设备日历时区计算自然日，与绝对日期显示一致。计划列表每分钟及回到前台时更新；聊天中的时间行按分钟更新。中文、英文、德文均有对应文案。
