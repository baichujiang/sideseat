# Preview212：计划活动名称与地点编辑区

2026-10-24，Europe/Berlin。**最终同包专项468.029秒、完整原生链371.918秒和8阶段API全部通过；32张专项＋25张完整流程原图逐张终审通过。默认手机Preview212普通启动PID8816、构建来源及清理已核验。** 初版及未通过范围单列。

## 本轮改动

共同计划详情的活动名称和地点原位编辑改为两个明确的字段：

- 字段上方固定显示「Activity name」与「Location (optional)」标签，输入后标签仍保留。
- 两个字段复用现有`SSFieldChrome`的圆角和`fillTertiary`背景；名称沿用标题字体及1–3行显示，地点改为相同1–3行输入视口，长内容在框内滚动编辑，保留原200字符上限。
- 取消、保存集中在右侧。`ViewThatFits`优先并排，空间不足时右对齐纵排；沿用原次操作与实色主操作样式、至少44pt命中区。
- 详情显示态仅在存在原编辑回调时附轻量铅笔装饰；文字与铅笔所在区域仍进入同一个原位编辑，不新增独立编辑页面或按钮。
- 信息区底部加入轻`Divider`，与活动提议／时间表分层。

产品改动仅在`PlanDetailEditors.swift`、`PlanFlowViews.swift`和`SSTextField.swift`。Core中的`SSFieldChrome`仅由`private`改为模块内可见，复用同一背景实现，没有修改公共字段样式或新增依赖。

## 权限、请求与流程保留

编辑权限仍来自原`COLLECTING && isOwner && selectedIdeaId == nil`判断，`canMutate`禁用保持；参与者、已选定活动以及邀请／已确认详情不因铅笔装饰获得编辑权限。共享只读标题调用未传编辑回调，因此不出现铅笔。

`begin`仍从当前计划复制名称／地点；取消仍结束本地编辑。保存沿用原trim、非空活动名、名称120／地点200字符校验、变更判断及并发保护。`PATCH details`和`UpdateTimePollDetailsRequest(title: trimmedTitle, location: trimmedLocation)`构造代码未改，没有新请求或编码规则。

保存仍等待原`store.mutate`，仅`store.error == nil`时退出编辑；失败保留输入，错误继续由原详情错误区处理。空闲草稿及手动提交、首次提交后分享、活动选择、最终选时、邀请版本、接受／主动发出与Calendar规则均未修改。`begin`／`save`及请求构造代码没有因布局或行数修正改变；最终包请求结果与草稿保留以本轮实际测试为准，不以静态审查替代。

原字段`plan-edit-title`／`plan-edit-location`、取消／保存、标题／地点ID及文字上的Edit辅助操作保留。新增固定标签、编辑区和操作区ID仅供定位；装饰铅笔对辅助功能隐藏，字段及操作仍为可访问子元素。
