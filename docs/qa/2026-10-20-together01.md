# 同行交互修复 1：私密收藏语义

2026-10-20，Europe/Berlin。逐项修复必须在当前项闭环通过后才进入下一项。

## 行为

推荐与探索共用的私密保存按钮统一为「收藏／已收藏」（English Save/Saved；Deutsch Merken/Gemerkt）。收藏成功以「已收藏，仅自己可见」提示及读屏播报解释隐私；取消收藏、打招呼、书面回复和计划规则保持。

## 闭环验证

- 最终真实原生双账号完整闭环 **166.158 秒通过，0 失败、0 跳过**：双方发布意愿 → 推荐收藏 → 我的收藏 → 发送首条招呼 → 对方书面回复 → 原聊天提议计划 → 对方明确确认 → 双方日历。
- 三个阶段独立读取隔离 PostgreSQL：收藏只有本人 1 条 bookmark，招呼/聊天/计划/日历均为 0；发送后只有 1 条招呼、仍无聊天；书面回复后创建 1 个聊天，计划及日历仍为 0。[阶段核对](./evidence/2026-10-20-together01/api-boundaries.json)。
- 最终独立持久化核对：1 条私密收藏、1 个聊天、1 个 ACCEPTED 计划、双方各 1 条日历，招呼与回复各保存一次。[持久化结果](./evidence/2026-10-20-together01/persistence.json)。
- 中文收藏/取消/重新收藏/首条消息/等待回复/收藏返回聊天，以及德文深色最大字号 **2 项 UI 检查通过**。中文用例同时断言可见的「收藏」「已收藏」和隐私提示。[两项界面检查及原完整用例失败记录](./evidence/2026-10-20-together01/simulator-r2-summary.json)、[最终完整闭环](./evidence/2026-10-20-together01/simulator-r3-summary.json)。
- 首轮基础验证中的 448 项 Swift Testing 及原有 XCTest 通过；三语 strings、专用数据核验脚本 ESLint、git diff 检查通过。
