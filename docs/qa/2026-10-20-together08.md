# 同行：更多推荐无结果时的状态提示

用户报告：点击「更多推荐」后没有新结果，页面出现位置突兀的「重试」按钮。

原因：成功返回空数组时，内嵌探索列表另外创建了左对齐的 bordered 重试按钮；根页面原本已在结果耗尽时收起整行寻找入口。

修复：正常空结果只保留居中的「暂时没有新的推荐」，增加上下留白，多行居中且大字号不截断。加载失败仍沿用根页面已有的整行重试入口；独立探索页的错误重试不变。没有后端、网页、Schema 或数据变更。

模拟器闭环已通过：点击更多推荐 → 原整行按钮加载中并禁用 → 空结果居中、没有重试按钮 → 打开空收藏 → 返回推荐，状态仍正确。覆盖中文已有推荐、德文深色最大辅助字号且完全无推荐两个场景；另复验空探索下收藏 → 收藏页查看 → 返回推荐，已有卡片仍可操作。两个用例均 0 失败／0 跳过，截图已人工查看。

首轮脚本在「完全无推荐」样例启动后没有先切换到推荐页，误操作屏幕外的推荐页滚动容器。脚本已明确选中推荐页后完整重跑通过；初轮失败摘要单独保留，未以失败场景代替验收。
