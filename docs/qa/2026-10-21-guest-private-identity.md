# 游客独立身份、个人恢复链接及旧记录迁移

用户批准：无需注册登录，同名不串记录；提供个人恢复链接；首次填写、再次打开、清除缓存恢复、多人同名完成闭环后上线。

当前实现与 [身份合同](../GUEST_IDENTITY.md) 一致。独立随机凭证只以摘要保存在数据库，名字不再认领身份；私密恢复 fragment 经 POST 校验，恢复原 guest / response，而不是新建记录。原随机浏览器凭证自动升级，只有原 ID Cookie 的记录需由发起人确认后私下发送恢复链接；领取后拒绝发起人重置。

本地独立数据库 sideseat_guest_identity_20261020、活跃项目 3106 端口：Chromium / WebKit 的首次填写→重开→多人同名→清除 Cookie 和 localStorage→原页面及新页面恢复→各自回复邀请→发起人发布→Calendar，以及旧随机凭证升级、ID Cookie/私钥伪造、跨人写入、跨计划恢复、非发起人重置拒绝及并发同名均通过。旧记录恢复另核对原 response / invitation ID、已接受回复与时间保留，不创建额外日历。相关 14 项时间表领域测试通过，TypeScript / 相关 ESLint 通过。

初轮发现同页打开带 fragment 的恢复链接不触发页面加载，已加入 hashchange 处理并复验；后续脚本需等待邀请保存请求完成再读库，以及账号删除补充既有 Idempotency-Key，均已修正后重跑。原生入口首轮脚本将完整 URL 传给只接受路径的 QA 深链入口，正在以正确路径复验；未将该脚本失败称为原生通过。

发布前发现计划时段显示已由并行阶段上线，已切换至当前正式 dpl_2ifkV5RZ2Dy2cguEeBfoaAo7LLWj 的 1,380 项源码逐项 SHA1 校验，保留其连续受邀时段改动。候选仅覆盖 13 项功能文件，保留其他 1,372 项生产源文件。独立 /time-poll-recovery/ 网页入口避免被已安装 App 的通用链接拦截。没有 Schema 或数据库迁移。已通过旧正式 API 为专用测试账号预留旧格式填写，用于候选与正式迁移验证；最终需全部回收。
