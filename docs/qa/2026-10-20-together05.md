# 同行交互修复 5：意愿和招呼草稿

第 4 项完整验收及最终后端提升后开始本项。输入随编辑保存在此设备，关闭时补一次保存；取消／下滑关闭只关闭表单，成功发布或发送才清除。空白表单不制造“已恢复草稿”提示。

按账号、意愿版本、重新发布来源、原计划，以及推荐和发送／回复方向隔离；草稿保留活动、类别、已确认时间选择、描述与公开设置。仅恢复输入，不自动发布、发招呼、恢复寻找或创建聊天。来自已完成计划的草稿使用原计划 ID 区分。

真实账号闭环独立验证：关闭前后服务器没有意愿；换账号不出现原输入；原账号重登录恢复并发布；另一账号招呼关闭后没有招呼或聊天；再次登录恢复后明确发送，服务器只保存一条招呼。真机界面闭环另外覆盖时间恢复、下滑关闭、成功发布后新表单为空，以及成功发送后重开不恢复旧招呼。

本项不改后端、Schema、迁移或网页。

最终真实原生用例及四个读库阶段通过，0 失败／0 跳过。默认手机的中文意愿／时间／招呼草稿完整界面闭环通过，包括实际下滑关闭和成功后清空。源码和手机包按本项单独记录交付。
