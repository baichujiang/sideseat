# Preview 125 横向分区与完整真机流程

2026-10-18，Europe/Berlin。采用用户选定的「横向分区」：需要自己处理的计划纵向集中，
等待其他人的计划横向展示。[userflow 基准版本 1](../PLAN_FLOW_BASELINE_2026-10-18.md) 保留。

## 页面与操作

- 需要你处理：一张分组底板内纵向排列，活动、状态、时间和下一步可直接扫读，点击进入原详情。
- 等待其他人：横向卡片、边缘预览、按卡片停靠和「查看全部 / 收起」。仅一张时填满可用宽度。
- 横滑起点归卡片轨道所有，不触发外围「待安排 / 即将开始 / 历史」翻页；展开后仍能打开同一计划。
- 最大辅助字号自动改为纵向并完整换行，避免把大量文字挤进窄卡片。
- 已有计划时创建和链接入口不再套一层大卡片；用途示例保留。空账号的完整用途说明不变。
- 下一次见面采用轻量日期摘要。即将开始、历史、聊天详情及结束反馈保留原入口和规则。
- 只修改展示和导航布局，没有改邀请名单、确认事务、版本、保存、通知或日历规则。

## 发现并修正

初始展开容器的辅助功能标识被继承到每张子卡片，覆盖原卡片标识；已显式设置子元素容器边界，
保留各卡片原有标识。测试查找也改为按屏幕位置向上或向下滚动。普通横滑断言验证最后一张完全进入
视口、主分组仍为待安排，展开后的行坐标为纵向，并可收起后打开、返回。

初次真机两项失败、第二次一项通过两项失败，以及首次模拟器批次两项呈现失败均保留：
[首次真机](./evidence/2026-10-18-plans125/phone-first-layout.json)、
[第二次真机](./evidence/2026-10-18-plans125/phone-second-layout.json)、
[首次模拟器](./evidence/2026-10-18-plans125/simulator-first-layout.json)。
没有把这些执行记为全绿；产品修正后以上最终真机批次重新通过。

第一次 Safari 执行在 URL 输入过程中连续出现 60 秒动画完成等待，主动中止；实际分享网页返回 HTTP 200。
之后只重启 Safari 进程，保留标签页与网站数据，用新的账号/计划完整重跑并通过，没有删浏览记录。
