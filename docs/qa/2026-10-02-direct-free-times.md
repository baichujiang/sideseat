# 智能约时间：直接推荐空闲时段（2026-10-02）

按用户纠正，替换 Preview 66 的分享式入口：点击聊天中的「智能约时间」直接读取自己的已同步日程，显示三个具体日期与起止时间。无日期范围设置、时长选择、分享配置或旧分享页面；「换一组」浏览更多时段。

选择一个时段后进入当前标准计划确认页，预填开始和结束时间，并保留已有活动上下文。确认发送后走原有计划提议／接受／双方日历流程。推荐时段仅表示自己有空，对方仍需确认；打开、换组和关闭均不会发消息或创建分享链接。

计算范围为从明天起七天、柏林时间 09–21 点。按上午、下午、晚间提供真实连续空闲窗口，最短 30 分钟；优先不同日期，避免把整块空闲拆成大量一小时预约选项。无空闲或读取失败都有明确状态。本轮未改服务器或数据库，不调用大模型。

## 本轮验证

- Xcode Development 构建和 13 项测试通过：9 项计算测试（含历史共享计算回归）与 4 项 UI 测试。
- 验证三／四小时完整窗口、忙碌间隙不被连通、来源重叠合并、跨日选择及柏林冬令时。
- 模拟器验证：一击直接出现三条 → 换组循环 → 选择 → 计划起止时间为 09:00–12:00 → 提交 → 返回聊天并出现计划卡。
- 取消后不打开计划；重新进入正常。空数据和失败不生成假推荐。
- 检查截图：日期、时间、换组入口及预填计划内容在 iPhone 13 mini 可读。
- 中文、英文、德文资源 `plutil` 与 `git diff --check` 通过。

本轮 UI 使用本地认证 fixture，未向真实联系人发送消息。本轮无新增双账号 HTTP 测试；复用的读取接口与标准计划提交接口未改，旧分享式 HTTP 测试记录不能视为本轮新交互的端到端证明。实际尚未同步的日程不能参与推荐。
