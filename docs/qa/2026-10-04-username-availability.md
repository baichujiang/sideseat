# 用户名输入阶段查重

2026-10-04，Europe/Berlin。

分享页快速注册和原生 App 注册页在输入停顿 400ms 后查重，离开输入框时立即检查尚未完成的结果。输入框下方显示检查中、可用、已占用或格式提示；检查中、重名和格式不合法时不允许提交。取消旧请求并校验当前输入，避免过期响应覆盖新名称。检查服务异常显示提示，允许提交时进行最终验证。

新增公开 POST `/api/auth/username-availability`，复用注册的格式、保留字和大小写标准化规则，只返回规范化用户名与可用状态；响应不缓存，按 IP 限制为每分钟 60 次。最终注册的唯一性校验和数据库约束保持生效。

验证结果：

- 浏览器/API 三项通过：真实数据库重名与大小写/空格标准化、可用名称、保留字、最终注册重名拒绝；分享页旧请求返回、检查失败恢复、注册后恢复日程操作；分享页语言回归。
- 模拟器原生用户名查重 UI 用例通过：大写输入已占用名称 → 可用名称 → 改回重名 → 可用名称，正常填完其余信息后创建按钮启用。
- 德文普通与最大辅助字号注册说明回归通过；12 项认证会话测试通过。
- 原生模拟器与真机签名构建通过；定向 ESLint、源码 TypeScript、diff 检查通过。
- 候选云构建包含正式 lint/type 检查，146 个现有迁移状态同步，无新增数据库迁移。

原生新用例前三轮在跨密码框切换/回到用户名时未获得键盘焦点，未通过的轮次没有计入成功。调整自动化为正常填写顺序并在下一项后明确选中确认密码框，最终完整用例通过；未为测试改动产品的密码控件。手动检查了原生用户名输入与失败提示。
