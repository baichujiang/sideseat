# 五个一级页面统一底板 · 提案 v1

这是供确认的独立本地设计稿，只调整五个一级页面的共同视觉底板。现有 App 源码、业务规则和手机 Preview 均不覆盖；仓库当前记录的原生版本仍为 Preview 218。本目录使用演示内容，不连接账号或后端。

## 查看方式

直接打开 [index.html](./index.html)，可离线切换「同行、计划、日历、消息、我」。截图保存在 `screenshots/`；在已安装项目 Node、Playwright 与 Chromium 的环境中，本目录执行 `node render.mjs` 可重新生成。设计参数另存为 [tokens.json](./tokens.json)。

## 固定的共用样式

- 画布为 428 × 926；顶部状态区 54，高度 58 的抬头固定在其下。品牌图标 22、标题 20；左右各留 44 的工具点击区，工具数量不影响标题居中。
- 内容左右留白 20，基础间距节奏为 4 / 8 / 12 / 16 / 20 / 24 / 32，局部按内容调整。主要卡片圆角 24、设置分组圆角 20、搜索框圆角 14；胶囊操作使用对应的完整圆角。
- 背景 `#F7F7F3`、卡片 `#FFFFFF`、正文 `#1C2421`、次要文字 `#747B75`、分隔线 `#E7EAE3`、浅底 `#EDEFE8`、主要操作 `#26322D`。图标入口不普遍增加轮廓。
- 底部导航占据独立的 112 高布局区，与滚动内容分开。白色胶囊栏距左右 20，高度 78，上方留 12、距画布底部 22；内部为五个等宽点击区，下方保留系统指示条。滚动内容本身底部留 20，计划页另有独立的主操作区，均不叠盖列表。
- 需要分栏时使用轻下划线；搜索、视图控制和账户信息按原页面功能保留。共同底板不强迫每页增加相同的工具按钮。

## 各页保留的差异

| 一级页面 | 现有内容与入口 |
| --- | --- |
| 同行 | 保留「我的意愿 / 推荐 / 我的收藏」，默认展示推荐。 |
| 计划 | 保留「筹划中 / 已确定」、纵向待处理与横向等待分区；发起计划仅放右下。整卡入口的视觉方案不重复添加卡内按钮或活动装饰图；人员头像位置保留，使用本地演示素材。 |
| 日历 | 保留周视图、月份、搜索、连接、分类和新增入口。 |
| 消息 | 保留通知、新招呼、搜索和会话列表。 |
| 我 | 保留身份信息、资料管理与设置行，不增加无实际功能的顶部工具。 |

本轮不修改路由、后端、数据结构、邀请与日历规则，不增加 App 功能，不构建或安装手机版本。仅底部五入口支持原型页面切换；其他入口为视觉示意，未接入 App 功能。确认设计后再进入 App 实现与原生验收。
